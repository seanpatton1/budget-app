# Budget

Household budget app for tracking income, outgoings, debts and one-off expenses.
Built as an installable PWA — no app store needed.

**Live app:** https://seanpatton1.github.io/budget-app/

## Install on your phone

1. Open the live app link above in your phone's browser (Safari on iPhone, Chrome on Android).
2. **iPhone:** tap Share → "Add to Home Screen".
   **Android:** tap the ⋮ menu → "Install app" (or "Add to Home screen").
3. It now opens fullscreen from its own icon and works offline.

On a laptop/PC just open the same link in any browser.

## Sharing data between devices

Data is stored on each device. To share:

- **More → Export data** saves `budget-data.json` — put it in a shared OneDrive folder.
- **More → Import data** on the other device loads that file.

## Features

- **Home** — monthly income vs outgoings, leftover, total debt, and payments due in the next 7 days
- **Income** — per-month earned + transferred-to-joint for Sean and Martina
- **Outgoings** — direct debits, subscriptions, expenses and personal outgoings with due dates and accounts
- **Debts** — balance history per debt with monthly updates
- **More** — one-off spending log, export/import, reset

Starting data was imported from the "Budget 2025" spreadsheet.
